# Проектная работа 11-го спринта Stellar Burgers

## Описание проекта

**Stellar Burgers** — это интерактивное React-приложение для заказа космических бургеров. Пользователи могут:
- Собирать кастомные бургеры из доступных ингредиентов
- Оформлять заказы
- Отслеживать историю заказов
- Авторизовываться через защищённые роуты

Проект реализован с использованием современных технологий фронтенд-разработки и интегрирован с REST API. Применены лучшие практики работы с Redux для управления состоянием приложения.

👉[Открыть сайт](https://artem-736.github.io/stellar-burgers-main)

---

## Основной функционал

🍔 **Конструктор бургеров**
- Drag-and-drop сборка бургера
- Разделение ингредиентов по категориям (булки, соусы, начинки)
- Расчёт общей стоимости

🔐 **Система авторизации**
- Регистрация и вход
- Восстановление пароля
- Защищённые роуты
- Обновление токенов

📦 **Работа с заказами**
- Создание нового заказа
- История заказов
- Детализация каждого заказа

Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. Сама ссылка находится в файле `.env.example`.

## Настройка проекта

Перед запуском создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
### Запустите проект:
```bash
npm install
```
```bash
npm start
```

### Приложение будет доступно по адресу: http://localhost:4000
